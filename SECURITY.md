# Security policy

This repository is private. Report a problem with the live site or the CMS to the maintainer directly, using the contact details on https://rioku.dev, and do not put credentials, tokens or user data in issues.

If this repository is ever made public, enable GitHub private vulnerability reporting and replace this file with the standard policy from the organization.

## Scope

- Private content reachable on the public site or feeds (drafts, private entries, unpublished mods).
- Secrets, tokens or credentials in the repository or in build output.
